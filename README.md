# EduFlow｜智能作业系统

EduFlow 面向教师和学生，把布置练习、在线作答和课后反馈串成一套流程。教师可以跟踪任务完成情况和易错题，学生可以在提交前检查答题进度。

## 产品流程

### 教师发布练习

教师选定班级和题目，确认后发布打卡任务。发布时固定接收学生名单和题目内容，便于后续按同一口径统计完成情况。

![教师端的打卡发布成功页](screenshots/01-teacher-publish.png)

### 学生作答并提交

学生在题卡上作答，页面显示已填写题数。完成后，学生可以继续检查，也可以确认提交。

<img src="screenshots/02-student-answer.png" alt="学生作答页，展示单选题和填写进度" width="420">

<img src="screenshots/03-student-submit.png" alt="学生提交前的确认对话框，提供继续检查与确认提交两个选项" width="420">

### 教师查看学情

教师可以按班级和任务查看接收人数、已提交人数、完成率和班级平均正确率。完成率以发布时固定的名单为分母，平均正确率按已提交记录统计。

![教师端的班级学情概览，具体班级和统计数值已遮盖](screenshots/04-teacher-insights.png)

## 技术实现

项目使用 Next.js、TypeScript 和 PostgreSQL。发布、提交和统计由服务端处理。发布时保存名单和题目的快照，班级成员或题库后续变更时，历史任务仍可按发布时的内容核对。
